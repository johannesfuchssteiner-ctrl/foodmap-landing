# FoodMap Landingpage

Landingpage für FoodMap (Lebensmittel-Rettungs-Marktplatz).

## Setup GitHub Pages
1. Neues Repo erstellen, z.B. `foodmap-landing`
2. `index.html` hochladen
3. Settings → Pages → Branch "main" → "/ (root)" → Save
4. Live nach 1-2 Minuten unter:
   `https://<dein-github-username>.github.io/foodmap-landing/`
